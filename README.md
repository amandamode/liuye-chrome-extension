# 留页 · 标签与待读

给没看完的网页一个位置，收好以后再慢慢看。

留页是本地运行的 Chrome 浏览器插件。当前本地试用版 **0.3.0**，不需要账号、API Key 或安装第三方运行依赖。没有内置 AI 模型；它可以把网页正文整理成阅读材料，由你复制到已有 AI 聊天中处理。

## 能做什么

- 集中查看普通窗口的网页标签，按窗口筛选、搜索和批量保存。
- 只按完整网址检查重复页；保留参数和段落标识的差异。
- 保存待读、收藏、主题、备注、阅读笔记及你手动标记的阅读状态。
- 提取所选网页正文，复制给 AI，再把总结粘回笔记。
- 导出 Markdown，手动放入 Obsidian；导出及导入 JSON 收藏备份。
- 先保存再尝试收起标签；可重新打开最近收起的网址。

## 安装

要求：Chrome 120 或更高版本（以插件声明为准）。当前使用开发者模式安装，没有 Chrome 应用商店安装链接。

1. 如果本仓库已有 Releases，下载 `liuye-chrome-extension-v0.3.0.zip`；也可以选择 **Code → Download ZIP** 下载源码。
2. 解压到一个固定文件夹，确认里面有 `manifest.json`。
3. 在 Chrome 地址栏输入 `chrome://extensions`。
4. 打开右上角的 **开发者模式**，点击 **加载已解压的扩展程序**。
5. 选择直接包含 `manifest.json` 的文件夹。
6. 点击浏览器拼图图标，固定「留页」，然后点击插件图标打开管理面板。

保留安装文件夹。升级已有安装时，先导出收藏备份，再更新该文件夹里的文件并在扩展管理页点击重新加载；无需先卸载。更换文件夹或重新安装可能改变安装身份，不保证继承旧数据。

详细步骤见 [开始使用](开始使用.md)，插件内也有使用说明。

## 第一次使用

1. 保持「自动整理重复页」关闭，先用两个普通测试网页试用。
2. 点击 **稍后读**，在「稍后阅读」确认保存成功；原标签不会关闭。
3. 点击 **帮我读**，按需授权所选网站，提取正文后选择 **复制给 AI**。
4. 检查复制内容，再粘贴并发送到你正在使用的 AI 聊天。
5. 把总结粘回「阅读笔记」并保存。「我已读完」由你自己标记。

## 权限与隐私

标题、网址、收藏、笔记、正文及关闭记录存于本机浏览器。当前代码不接入远程模型、统计服务或项目服务端。

- `tabs`：显示、切换、保存、打开和收起网页标签。
- `storage`：保存本机数据。
- `scripting`：检查页面状态，提取你选中页面的文字。
- `alarms`：自动整理开启时定时检查重复页。
- 网站访问权限为可选；单篇提取按网站申请，批量去重或自动整理会申请所有 HTTP/HTTPS 网站权限。

复制并发送到 AI 聊天后，所发送的内容由该服务处理。导出的 JSON 和 Markdown 也可能含私人网址、笔记或正文，请自行保管。详见 [隐私说明](PRIVACY.md)。

## 使用边界

- 自动去重默认关闭。正在使用、固定、播放、休眠、加载中、有编辑区或无法检查的页面会保留，但不能证明任意网页的未保存状态都可检测。
- 恢复仅重新打开网址，不恢复表单、滚动位置或页面内存；恢复操作会暂停自动整理。
- 正文提取不是专业解析器，可能包含噪音或遗漏。最多 60,000 字符；不绕过付费墙，PDF、图片、视频和部分动态页可能无法提取。
- 不管理浏览器内置页、扩展页及无痕标签；不自动创建 Chrome 原生书签。
- 不提供跨设备同步。卸载扩展可能清除收藏，请定期备份。
- 不自动总结，不自动写入 Obsidian；保存网址也不是完整离线网页归档。

## 开发与验证

项目采用原生 JavaScript 模块，运行插件无需安装依赖。开发测试需要 Node.js，可运行：

```sh
npm test
```

测试使用模拟 Chrome API，覆盖重复网址、受保护标签、先保存后关闭、页面跳转、导入合并和消息来源等规则。自动测试通过不代表在所有真实网页上都通过；发布副本的本次浏览器人工验收仍待完成。
