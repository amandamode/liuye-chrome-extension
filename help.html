留页，先收好再慢慢看。

这是本地安装的 Chrome 插件试用版，不需要账号，也不需要 API Key。

安装一次

  1. 解压插件压缩包。
  2. 在 Chrome 地址栏输入 chrome://extensions。
  3. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
  4. 选中直接包含 manifest.json 的插件文件夹。
  5. 点击 Chrome 的拼图图标，将“留页”固定，然后点击它打开管理面板。

你的三个常用动作

  • 稍后读：保存网址，标签页继续保留。
  • 保存并收起：先保存到本机，再尝试关闭。正在使用、有输入框或无法确认状态的页面不关闭。
  • 帮我读：授权读取这个网站，提取正文，点击“复制给 AI”，粘贴到你正在使用的 AI 聊天。AI 总结后，复制回插件的阅读笔记并保存。

去重的规则

只比较完整网址。不同参数、不同段落链接不会合并。你可以手动点“整理重复页”，或开启自动整理（会申请网页访问权限）。自动模式在网页加载完成时及每分钟检查一次；保留正在使用、固定、播放、休眠中的页面，以及有输入框、编辑区、嵌入页面或检查失败的页面。自动模式默认关闭。

网页的所有内存状态无法可靠检测，所以仍不保证零损失。重要表单或工作页面请固定标签页。恢复功能只重新打开网址，不恢复表单、滚动位置或登录会话。恢复前会自动暂停自动整理，避免刚恢复的页面又被收起。

收藏、备份与 Obsidian

给保存的页面填写主题和留下的理由，标记收藏；“我已读完”只由你手动标记。搜索支持标题、网址、主题和理由。“导出到 Obsidian”下载 Markdown 文件，你需要把文件放入自己的 Obsidian 库；本版不自动写入本地库。

收藏和正文保存在 Chrome 本机 storage.local。卸载扩展可能清除数据，请定期“导出收藏备份”，重装后可导入。不提供跨设备同步；保存网址不是离线网页存档，页面删除或登录过期后可能无法重现。

提取范围与隐私

插件不连接模型、不自动上传标签或正文，不包含统计服务。页面标题、网址用于展示和查重；网站权限用于检查页面及提取你选择的正文。仅当你复制并发送到 AI 聊天后，正文才交给该服务。复制前请检查有没有不想发送的私人内容。

提取优先选 article、main，再回退到正文；不是专业正文解析器。只读取已加载的文字，最多 60,000 字符，超长会标注截断；PDF、视频、付费墙、图片及部分动态页面不支持或不完整。不根据停留时间和滚动位置推断“读完”。Chrome 内置页、扩展页和无痕标签不管理。
